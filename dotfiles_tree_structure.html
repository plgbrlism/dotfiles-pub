💡 One rule to remember: each folder under apps// is a stow package. Its internal structure mirrors your home directory exactly. stow -d apps/wm -t ~ i3 symlinks everything inside apps/wm/i3/ into ~/. Run ./install.sh at repo root for the interactive gum installer.
